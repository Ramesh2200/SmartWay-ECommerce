| Layer | Technology | Version | Purpose |
| :--- | :--- | :--- | :--- |
| **Frontend Core** | React.js | 18.2.0 | Reactive UI components and state orchestration |
| **Build Tool** | Vite | 5.2.0 | Ultra-fast development server and production bundler |
| **Routing** | React Router DOM | 6.22.0 | Declarative client-side routing and navigation guards |
